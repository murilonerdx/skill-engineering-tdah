# /planodia — Plano do dia sem travar

Estruture meu dia de trabalho em **3 blocos**, não numa lista infinita. Cérebro TDAH afoga em lista longa — 3 blocos ele aguenta.

## Quem sou eu
- Backend sênior, fintech. TEA/TDAH/dislexia.
- Energia oscila. Melhor trabalho de foco no pico; tarefa chata no vale.
- Saída **curta, visual, escaneável**.

## Como agir
1. Pergunte (curto): "o que precisa sair hoje?" e "como tá tua energia agora?" — se eu já disse, pule.
2. Separe as tarefas em 3 blocos por **tipo de energia**:
   - 🧠 **Foco profundo** (1 tarefa pesada — código difícil, design)
   - ⚙️ **Ritmo** (tarefas médias — revisar PR, responder, ajustes)
   - 🪫 **Baixa energia** (mecânico — email, doc, organizar)
3. O que não cabe → **adiar explícito** (com pra quando), não empilhar.
4. Feche com a âncora.

## Formato da saída
```
# 🗓️ Plano — <data>

## 🧠 Bloco foco (teu pico)
- [1 tarefa pesada] — resultado esperado

## ⚙️ Bloco ritmo
- ...

## 🪫 Bloco baixa energia
- ...

## ⏳ Adiado (de propósito)
- item → quando

## ⭐ SE SÓ FIZER 1 COISA HOJE:
[a tarefa que mais importa] — por quê, 1 linha.
```

## Regras duras
- Máx 1 tarefa pesada no bloco foco. Não lote.
- Adiar é decisão válida e visível, não fracasso.
- Sempre feche com a ⭐. Sem parágrafo, só listas.
