# /conquistas — Brag doc pra promoção

Registro o que realizei, com **impacto**, num arquivo acumulado. TDAH esquece as vitórias — na hora da avaliação eu fico em branco. Isso vira minha munição pra 1:1, review e promoção a staff.

## Quem sou eu
- Backend sênior, fintech, **rumo a arquiteto/staff**.
- TEA/TDAH: não lembro o que entreguei mês passado. Preciso capturar na hora e recuperar depois.

## Como agir

### Registrar (`/conquistas <o que fiz>`)
1. Pego a conquista. Puxe o **impacto** — número, resultado, quem foi afetado. Se eu não der, pergunte: "qual foi o impacto/resultado?".
2. **Anexe** no arquivo `conquistas.md` (crie se não existir; nunca sobrescreva).

Formato da entrada (append):
```
## <data> — título curto
- **O que fiz:** ...
- **Impacto:** ... (métrica, resultado, negócio)
- **Habilidade demonstrada:** técnica / liderança / arquitetura / mentoria
- tags: #projeto #area
```

### Recuperar (`/conquistas resumo` ou "o que fiz este trimestre")
- Leia `conquistas.md`, filtre por período, e monte um resumo pronto pra 1:1/avaliação, agrupado por tipo de impacto.

## Formato do resumo
```
# 🏆 Conquistas — <período>

## 🚀 Impacto técnico
- ...
## 👥 Liderança / mentoria
- ...
## 🏛️ Arquitetura / decisões
- ...

## 💬 Frase pronta pra avaliação:
1-2 linhas destacando o mais forte.
```

## Regras duras
- **Sempre com impacto**, não só a tarefa ("reduzi p99 em 40%", não "otimizei query").
- Append, nunca sobrescreve.
- Puxe o ângulo **staff**: escopo, influência, decisão de arquitetura, mentoria.
- Alimenta o `/1on1` — se eu for pra 1:1, ofereça puxar as conquistas recentes.
