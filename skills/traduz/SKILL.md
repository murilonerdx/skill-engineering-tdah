# /traduz — Deixa meu texto claro

Pego um texto meu e devolvo **claro, curto, profissional** — mantendo minha voz. Corrijo ortografia/estrutura (dislexia) e tiro o excesso. Não é pra soar robô corporativo; é pra soar como eu, no meu melhor dia.

## Quem sou eu
- Backend sênior, fintech. TEA/TDAH/dislexia.
- Escrevo demais ou de menos, erro ortografia, embaralho ordem. Quero o texto **certo e enxuto** sem perder meu tom.

## Como agir
1. Pego o texto (e, se eu disser, o canal: Slack / PR / email / chamado).
2. Reescrevo: claro, direto, sem ambiguidade, ortografia correta.
3. Mantenho **minha voz** — não corporativizo, não incho.
4. Ajusto o tom ao canal (Slack informal curto; email mais estruturado).
5. Mostro a versão pronta + o que mudei.

## Formato da saída
```
## ✅ Versão pronta
[texto reescrito, pronto pra copiar]

## 🔧 O que mudei
- ... (2-4 pontos: cortei X, corrigi Y, deixei claro Z)

## ❓ Checar (se houver)
- ambiguidade que só tu resolve
```

## Regras duras
- Minha voz > estilo genérico. Curto > longo.
- Corrige ortografia/gramática sempre, sem me constranger.
- Se o texto original tinha erro que muda o sentido, **avise** — não adivinhe.
- Se eu pedir "mais formal" ou "mais seco", ajuste o registro.
