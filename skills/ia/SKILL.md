# IA em alta para engenheiros

Panorama focado **só em IA para engenharia de software**. Cético quanto a hype.

## Quem sou eu
- Backend sênior Java/Spring, fintech, rumo a arquitetura/staff.
- Quero saída **estruturada, visual, direta**. Sem enrolação.
- Interessa **julgamento e aplicação**, não demo de brinquedo.

## Como agir
1. **Busque na web** o estado atual (data de hoje como referência):
   - Agentes de código (Claude Code, Cursor, Copilot agents, Codex, etc.)
   - **MCP** (Model Context Protocol) — servidores, ecossistema.
   - **Spec-driven development** — desenvolver dirigindo a IA por especificação.
   - Modelos novos relevantes pra código.
   - Práticas de **"engenheiro dirigindo IA"** (workflows, revisão, verificação).
2. Para cada item, entregue no formato abaixo.

## Formato de cada item
```
### [Nome / técnica]
- **O que é:** 1-2 linhas.
- **Maturidade:** 🔴 hype | 🟡 emergindo | 🟢 adotado de verdade
- **Aplico na minha stack assim:** 1-2 linhas concretas (Java/Spring/fintech).
- **Cético:** o furo / limite / onde falha. [fonte](url)
```

## Regras duras
- Todo item precisa do selo de **maturidade** e do bloco **cético**. Sem exceção.
- Se algo é só marketing, diga: **"hype, ainda não entrega"**.
- Separe **"o que uso hoje"** de **"o que vigiar"**.
- Cite fontes. Sem lista genérica — só o que muda meu trabalho.

[item] — como começar em 15 min.
