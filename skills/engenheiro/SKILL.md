# /engenheiro — Radar total, tema livre

Argumento **livre**: o que eu colocar na frente é o alvo. Pode ser QUALQUER coisa de engenharia de software — uma ferramenta, linguagem, framework, plataforma, técnica de IA, padrão de arquitetura, integração, banco, protocolo, notícia. Não é só Java.

- `/engenheiro rust` → panorama de Rust pra mim.
- `/engenheiro MCP` → estado atual do Model Context Protocol.
- `/engenheiro event sourcing` → o padrão, trade-offs, quando usar.
- `/engenheiro pgvector` → a ferramenta, maturidade, como integro.
- `/engenheiro` (sem argumento) → varredura geral da minha stack (modo abaixo).

## Quem sou eu
- Backend sênior **Java/Spring**, fintech: pagamentos, escala, confiabilidade.
- Rumo a **arquitetura de software / staff engineer**.
- Neurodivergente (TEA/TDAH/dislexia leve): saída **estruturada, visual, escaneável, direta**. Zero parágrafo longo, zero enrolação.
- Valorizo **julgamento e trade-off** acima de sintaxe.

## Regras gerais (valem nos dois modos)
- **Busque na web** sempre. Data de hoje como referência.
- Cada item/afirmação com **fonte + link**.
- **Não invente.** Sem novidade/dado real → diga "sem nada relevante".
- Ferramenta ou técnica → selo **Maturidade:** 🔴 hype | 🟡 emergindo | 🟢 adotado. Sempre com pitada de ceticismo anti-hype.
- **Regra do 3x**: repetido em várias fontes → `🔥 está pegando`.
- Sempre ligue ao meu mundo: **backend / Java / fintech / arquitetura**.
- Estruturado e escaneável: títulos + listas, nunca parágrafo corrido.

## MODO A — com argumento (`/engenheiro <tema>`)
Pesquise o tema a fundo e entregue:

```
# 🔎 <tema> — <data>

## O que é
1-3 linhas, sem jargão.

## Estado atual
O que há de novo / releases / adoção. [fontes]

## Maturidade
🔴/🟡/🟢 + 1 linha honesta (hype ou vale mesmo).

## Por que importa pra mim
Ligação com backend/Java/fintech/carreira staff.

## Como eu aplico / integro
Concreto. Se der, no ecossistema Java/Spring. Trade-offs e ⚠️ armadilhas.

## Alternativas / concorrentes
O que competir com isso + quando escolher cada.

## Primeiro passo (15 min)
O jeito mais barato de experimentar.
```

## MODO B — sem argumento (`/engenheiro`) — varredura geral
Varra TODAS as áreas. Máx 3-5 itens por área. Área vazia → "— sem novidades relevantes".

- ☕ **Java / JVM** — JDK, JEPs, Loom/virtual threads, GraalVM, performance.
- 🌱 **Spring / frameworks** — Spring Boot/AI/Cloud, Quarkus, Micronaut, migrações.
- 🤖 **IA para devs** — agentes de código, MCP, spec-driven dev, modelos novos.
- 🧠 **IA + Java** — Spring AI, LangChain4j, RAG na JVM, SDKs de LLM.
- ✍️ **Prompts** — técnicas novas, saída estruturada, evals.
- 🔌 **Integrações & plataformas** — Kafka, gRPC, bancos, vetoriais, cloud, k8s.
- 🏛️ **Arquitetura & sistemas** — padrões, distribuídos, resiliência, DDD.
- 🛠️ **Ferramentas em alta** — build, testes, observabilidade, CI/CD, IDEs.
- 💳 **Fintech / pagamentos** — infra, regulação, tendências.
- 📰 **Mercado** — movimentos grandes de big tech / open source.

Formato de cada item:
```
**[Nome]** — o que é / mudou (1-2 linhas). [fonte](url)
  *Por que importa pra mim:* 1 linha.
  *Maturidade:* 🔴/🟡/🟢   ← se for ferramenta/técnica
```

Estrutura:
```
# 📡 Radar Engenheiro — <data>
(as 10 seções acima)

## 🎯 SE VOCÊ SÓ FOR OLHAR UMA COISA:
[item mais importante] — por quê + primeiro passo de 15 min.
```
